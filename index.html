1. 在網頁設計中，幫標題設定粉紅色、背景加上漸層，屬於「網頁三兄弟」中的哪一層？
解析：CSS 負責外觀與樣式（衣服），決定長相。
2. 當你在瀏覽器網址列輸入網址並按下 Enter 時，遠端伺服器回傳給你的本質是什麼？
解析：伺服器回傳給瀏覽器的其實只是一份寫滿標籤的純文字檔。
3. 在 VS Code 中安裝哪一個外掛後，只要按下存檔，瀏覽器就會自動重新整理畫面？
解析：Live Server 是 VS Code 的外掛，存檔即自動重新整理。
4. 在 VS Code 的空白檔案中，輸入哪一個符號再按 Tab，能瞬間長出 HTML 基本骨架？
解析：輸入一個驚嘆號 `!` 再按 Tab 即可利用 Emmet 魔法自動產生骨架。
5. 在 HTML 的 <head> 區塊中，哪一行是用來指定文字編碼以避免中文變成亂碼？
解析：`charset="UTF-8"` 指定了能夠表示全世界文字的編碼方式。
6. 關於 HTML 的名詞定義，下列何者正確？
解析：屬性是寫在開始標籤裡的額外設定，格式為名字=`"值"`。
7. HTML 巢狀結構（俄羅斯娃娃一層包一層）的基本關閉原則是什麼？
解析：巢狀結構的規則是後開的先關。
8. 關於網頁標題標籤 <h1> 至 <h6> 的使用原則，下列何者正確？
解析：選擇標題是看重要程度而非字體大小，h1 像書名一頁通常只放一個。
9. 當你在程式碼的段落中按下多次 Enter 換行或連續打多個空白時，畫面上會呈現什麼結果？
解析：瀏覽器具有「空白摺疊」規則，連續空白或換行會被壓成一個空白。
10. 如果要寫一個超連結，點擊後會在新分頁開啟外部網站，下列語法何者正確？
解析：超連結使用 `<a>` 標籤配合 `href` 指定目的地，並加上 `target="_blank"`。
